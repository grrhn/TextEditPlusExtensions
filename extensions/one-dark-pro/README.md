# One Dark Pro

Atom's iconic dark syntax theme ported for TextEdit+ Monaco Editor.

## Features
- Warm balanced palette (`#282c34` background, `#c678dd` keywords, `#61afef` functions, `#98c379` strings)
- Soft `#3e4451` selection highlight and `#528bff` accent cursor
- Italicized muted `#5c6370` comments for effortless scanning
