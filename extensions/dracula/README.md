# Dracula Theme

Dark purple-accented color theme for TextEdit+ Monaco Editor.

## Features
- High-contrast syntax tokens (`#ff79c6` keywords, `#50fa7b` functions, `#f1fa8c` strings, `#8be9fd` italic types)
- Comfortable `#282a36` editor canvas with `#44475a` active-line & selection highlight
- Automatically registers in **Settings / Theme Switcher** on install
